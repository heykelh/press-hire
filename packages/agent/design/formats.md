# Formats de jeu

Le format est le cadre narratif du jeu. Il change le rythme, les étiquettes des niveaux, l'ouverture et la fin.
Choisis celui qui sert le mieux le poste (ou l'idée) ; ne prends pas toujours « la semaine type ».
Chaque section commence par une ligne de résumé utilisée pour le choix.

## semaine
Résumé : la semaine type du poste, du lundi 9h au vendredi 17h ; sûr et réaliste, à réserver aux postes très routiniers.
Étiquettes : « LUNDI 9H », « MARDI 14H »… / « MONDAY 9AM »…
Ouverture : le badge qui bipe, le café, la première mauvaise surprise de la semaine.
Boss : le problème qui pourrit toute la semaine, qui explose le vendredi à 16h55.
Troll : le vendredi 16h59, « petite question rapide ».

## nuit-blanche
Résumé : une seule nuit de crise heure par heure (incident, clôture, livraison) ; parfait pour réagir, surveiller, corriger vite.
Étiquettes : « 22H00 », « 23H47 », « 02H13 », « 05H58 » / mêmes heures.
Ouverture : un téléphone qui vibre sur la table de nuit.
Boss : la panne totale à l'aube, juste avant l'ouverture des bureaux.
Troll : le chef qui envoie « tout va bien ? » à 3h du matin, puis se rendort.

## braquage
Résumé : un « casse » à l'envers façon film de braquage (repérage, équipe, plan, exécution, imprévu) ; idéal pour projets, migrations, audits.
Étiquettes : « PHASE 1 · REPÉRAGE », « PHASE 2 · L'ÉQUIPE », « PHASE 3 · LE PLAN », « LE JOUR J »…
Ouverture : un tableau en liège, des photos, une ficelle rouge.
Boss : le gardien du coffre (le vieux système, l'auditeur, le client) qui change les règles en direct.
Troll : le plan parfait qui rate pour une raison idiote (le mot de passe était sur un post-it).

## tournoi
Résumé : un tournoi à élimination façon jeu de combat, chaque round contre un adversaire-cliché du métier ; idéal pour vente, négociation, recrutement.
Étiquettes : « ROUND 1 », « ROUND 2 », « QUART DE FINALE », « DEMI-FINALE », « FINALE ».
Ouverture : l'annonceur qui hurle le nom du joueur.
Boss : le champion en titre, avec plusieurs formes.
Troll : un adversaire qui déclare forfait parce que « c'est l'heure de sa réunion ».

## emission-tv
Résumé : un jeu télévisé rétro avec présentateur, épreuves, public et buzzers ; idéal pour connaissances, conformité, culture métier.
Étiquettes : « ÉPREUVE 1 », « ÉPREUVE 2 », « LE DUEL », « LA SUPER FINALE ».
Ouverture : générique, applaudissements enregistrés, présentateur trop enthousiaste.
Boss : la super finale contre l'ancien champion.
Troll : la page de pub en plein milieu d'un niveau.

## boucle
Résumé : la même journée qui recommence en boucle, chaque boucle plus difficile, jusqu'à la bonne décision ; idéal pour processus et amélioration continue.
Étiquettes : « BOUCLE 1 », « BOUCLE 2 », « BOUCLE 7 »… (sauter des numéros fait rire).
Ouverture : le réveil qui sonne, la même chanson, encore.
Boss : la cause racine qui provoque la boucle.
Troll : un collègue qui dit « on s'est déjà vus, non ? ».

## survie
Résumé : tenir le plus longtemps possible sous une avalanche (tickets, colis, alertes, clients) ; idéal pour support, logistique, ops.
Étiquettes : « VAGUE 1 », « VAGUE 2 », « VAGUE 3 », « VAGUE FINALE ».
Ouverture : une file d'attente qui sort de l'écran.
Boss : la vague géante, en plusieurs formes.
Troll : la file s'arrête net… parce que le serveur de tickets est tombé.

## enquete
Résumé : une enquête policière façon polar rétro, indice après indice, jusqu'au coupable ; idéal pour analyse, audit, cyber, contrôle.
Étiquettes : « INDICE N°1 », « INDICE N°2 », « L'INTERROGATOIRE », « LA RECONSTITUTION ».
Ouverture : pluie, néon, un dossier qui tombe sur le bureau.
Boss : le coupable démasqué qui tente une dernière esquive.
Troll : le suspect idéal… qui a un alibi en béton (il était en congé).

## speedrun
Résumé : un défi chrono où tout doit être livré avant une échéance, avec splits et records ; idéal pour gestion de projet, production, livraison.
Étiquettes : « SPLIT 1 », « SPLIT 2 », « SPLIT 3 », « DERNIÈRE LIGNE DROITE ».
Ouverture : un compte à rebours géant.
Boss : la mise en production / la deadline personnifiée.
Troll : « nouveau record du monde ! » pour une tâche minuscule.

## quete
Résumé : une quête façon RPG en mondes (village, forêt, donjon, château) où chaque monde est un aspect du métier ; idéal pour apprentissage large et mode idée.
Étiquettes : « MONDE 1-1 », « MONDE 1-2 », « MONDE 2-1 »…
Ouverture : un vieux sage qui donne une mission absurde.
Boss : le gardien du château, dernier grand problème du métier.
Troll : le coffre au trésor qui contient… un formulaire à remplir.

## premier-jour
Résumé : le tout premier jour dans le poste, du badge qui ne marche pas au premier vrai succès ; idéal pour postes juniors, onboarding, reconversion.
Étiquettes : « 08H58 », « 10H30 », « MIDI », « 15H00 », « 17H45 ».
Ouverture : l'ascenseur, le badge refusé, l'accueil qui cherche ton nom.
Boss : le premier vrai problème qu'on te confie « parce que tu as un regard neuf ».
Troll : le mot de passe temporaire qui expire pendant qu'on le tape.

## simulateur
Résumé : un simulateur de gestion façon tableau de bord rétro où chaque niveau est une décision qui fait bouger des indicateurs ; idéal pour finance, pilotage, produit.
Étiquettes : « TRIMESTRE 1 », « TRIMESTRE 2 », « TRIMESTRE 3 », « BILAN ».
Ouverture : un tableau de bord qui s'allume voyant par voyant.
Boss : le conseil d'administration, le régulateur ou la crise du marché.
Troll : un indicateur qui monte… parce que quelqu'un a changé la formule.
